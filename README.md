# x-days-of-buh — учебный банк «Mini Bank»

Репозиторий для изучения **банковской бухгалтерии через практику**:
теория → схема данных → проводки → отчёты → автоматизация. Не курс лекций,
а маленький, но профессионально честный учебный контур розничного банка
на PostgreSQL + Python.

Что здесь происходит:

- заводишь справочники и факты в таблицах (план счетов, клиенты,
  лицевые счета, курсы валют);
- отражаешь операции проводками двойной записи — без «просто плюс/минус»;
- строишь оборотно-сальдовую ведомость, карточки счетов, дальше по плану —
  баланс и ОПУ;
- автоматизируешь на Python то, что делает бэк-офис: загрузка операций,
  генерация проводок, начисления, контроли закрытия дня.

**SQL — источник истины.** Схема, инварианты (двойная запись, закрытый
операционный день) и отчётные витрины живут в `db/`. Python не дублирует
учёт в pandas — он оркестрирует, считает и пишет проводки в БД.

Все данные синтетические: три вымышленных клиента, никаких реальных
реквизитов, карт, IBAN. См. `docs/assumptions.md`.

## Быстрый старт

Нужны: PostgreSQL 14+ и Python 3.11+ (psycopg 3).

### Вариант А: Docker

```bash
docker compose up -d                 # postgres:16 на localhost:5432
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m src.main                   # миграции + seed + демо-день + пробный баланс
```

### Вариант Б: локальный PostgreSQL (без Docker)

```bash
sudo -u postgres psql -c "CREATE ROLE minibank LOGIN PASSWORD 'minibank' CREATEDB;"
sudo -u postgres psql -c "CREATE DATABASE minibank OWNER minibank;"
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

Подключение настраивается переменными окружения:
`MINIBANK_DSN` (целиком) или `MINIBANK_HOST/PORT/DB/USER/PASSWORD`.
По умолчанию — `minibank:minibank@127.0.0.1:5432/minibank`.

### Ручной прогон SQL (без Python)

```bash
export PGPASSWORD=minibank
psql -h 127.0.0.1 -U minibank -d minibank -f db/migrations/0001_init.sql
psql -h 127.0.0.1 -U minibank -d minibank -f db/seeds/0001_seed_minibank.sql
psql -h 127.0.0.1 -U minibank -d minibank -v as_of='2026-01-07' -f db/queries/trial_balance.sql
```

## Первый день обучения (60–90 минут)

1. Прочитай `docs/module_01_theory.md` (15 мин).
2. Подними БД и запусти `python -m src.main` (15 мин). Прочитай вывод:
   5 проводок сквозного кейса + закрытие дня + пробный баланс.
3. Открой `db/migrations/0001_init.sql` и найди три триггера-инварианта
   (10 мин).
4. Прогони запросы из `db/queries/` на данных демо (20 мин):
   - пробный баланс: `trial_balance.sql`;
   - ОСВ: `osv.sql`;
   - карточка счёта Ивановой: `account_card.sql`
     (`-v acc='40817.810.00000000001'`).
5. Реши задачи `exercises/module_01.md` (30 мин), решения —
   в `exercises/solutions/module_01.md`.

## Что в реальном банке сложнее

Учебный контур намеренно узкий. Все сознательные упрощения (нумерация
счетов, один документ = одна проводка, учебные резервы и проценты,
один техсчёт конверсии и т.д.) перечислены в `docs/assumptions.md` —
читай его, когда возникнет вопрос «а так ли это в жизни».
